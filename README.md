# 🧙 RPG Character Creator (Spring Boot)

Projeto backend em Java com Spring Boot para criação de personagens inspirado em RPGs estilo Dungeons & Dragons 5e.

---

## 🎯 Objetivo

O sistema permite criar, armazenar e gerenciar personagens de RPG, com foco em:

- Aplicação de Programação Orientada a Objetos (POO)
- CRUD completo (Create, Read, Update, Delete)
- Regras de atributos inspiradas em D&D 5e
- Integração com banco de dados PostgreSQL

---

## 🛠️ Tecnologias utilizadas

- Java 25
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Git & GitHub
